# RE.Presentation

> **CURRENT:** Shared presentation project exists; complete canonical H6 views are TARGET.

Presentation consumes **RE Platform Core** services. It does not own storage, policy, planner/model loop or canonical Evidence. H6 projects/cases/runs/findings/reports and supplied ExternalSessionLink views work with no own Agent Runtime.

Optional agent actions remain client requests to H7 Runtime or a supported external host. Framework-specific controls live in the relevant UI project. See [Architecture](../docs/ARCHITECTURE.md) and [Strategy](../STRATEGY.md).
