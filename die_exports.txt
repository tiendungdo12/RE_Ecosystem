1. DIE_LoadDatabaseA
--------------------------------------------------------------------------------
Signature (C/C++):
    int DIE_LoadDatabaseA(const char* pszDatabasePath);

Description:
    Loads the signature database (.sg files) into memory. This must be called 
    AT LEAST ONCE before performing any file or memory scans. If you don't load 
    the database, all scans will return "Unknown".
    
C# P/Invoke:
    [DllImport("die_core.dll", CallingConvention = CallingConvention.Cdecl, CharSet = CharSet.Ansi)]
    public static extern int DIE_LoadDatabaseA(string databasePath);


2. DIE_ScanFileA
--------------------------------------------------------------------------------
Signature (C/C++):
    char* DIE_ScanFileA(const char* pszFileName, unsigned int nFlags, const char* pszDatabasePath);

Description:
    Scans a file located at `pszFileName` using the signatures loaded from 
    `pszDatabasePath`. The `nFlags` argument allows passing specific scanning 
    modes (usually 0 for default mode, which returns JSON or plain text depending
    on how the library was compiled).
    Returns a pointer to a dynamically allocated C-string containing the results.

C# P/Invoke:
    [DllImport("die_core.dll", CallingConvention = CallingConvention.Cdecl, CharSet = CharSet.Ansi)]
    public static extern IntPtr DIE_ScanFileA(string fileName, uint flags, string databasePath);


3. DIE_FreeMemoryA
--------------------------------------------------------------------------------
Signature (C/C++):
    void DIE_FreeMemoryA(char* pszMemory);

Description:
    CRITICAL: Frees the memory allocated by `DIE_ScanFileA` or `DIE_ScanMemoryA`.
    Because the DLL allocates the result string using its own C-Runtime (CRT), 
    the caller MUST pass the pointer back to the DLL to be freed. Failing to 
    call this function will result in a severe memory leak.

C# P/Invoke:
    [DllImport("die_core.dll", CallingConvention = CallingConvention.Cdecl)]
    public static extern void DIE_FreeMemoryA(IntPtr ptr);


Example C# Wrapper Implementation
================================================================================
public static string Scan(string filePath, string dieDbPath)
{
    // 1. Ensure DB is loaded once globally
    if (!_databaseLoaded)
    {
        DIE_LoadDatabaseA(dieDbPath);
        _databaseLoaded = true;
    }

    // 2. Scan file
    IntPtr ptr = DIE_ScanFileA(filePath, 0, dieDbPath);
    if (ptr == IntPtr.Zero) return null;

    // 3. Read & Free Memory
    try
    {
        return Marshal.PtrToStringAnsi(ptr);
    }
    finally
    {
        DIE_FreeMemoryA(ptr); // ALWAYS call this to prevent leaks
    }
}
