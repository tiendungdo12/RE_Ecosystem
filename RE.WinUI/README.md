# RE.WinUI

> **CURRENT:** Existing WinUI 3 executable; full canonical H6 integration is TARGET.

This is **RE Command Center**, the optional Windows control plane over RE Platform Core. Manual/deterministic analysis and shared Core records do not need our RE Agent Runtime/AI Harness. GUI is not the required H3 Platform host or canonical store.

H6 displays supplied ExternalSessionLink metadata and available summaries/artifacts without assuming full transcript/live status/control. H7 can add optional own-runtime actions; UI remains a client rather than implementing the agent loop.

Prove H3 Core access with GUI and own Runtime absent, and H6 shared-state/manual workflows without Runtime. See [Architecture](../docs/ARCHITECTURE.md), [Strategy](../STRATEGY.md), [CURRENT](../docs/CURRENT_STATE.md), [AGENTS](../AGENTS.md).
